# 📱 Projeto Cuida+

**Cuida+**, um aplicativo desenvolvido para auxiliar no controle de medicamentos dos usuários, oferecendo cadastro, notificações e gerenciamento de uso.

---

## 🎯 Objetivo
O objetivo do projeto é proporcionar uma ferramenta simples e intuitiva que permita ao usuário organizar seus medicamentos, recebendo lembretes nos horários corretos e mantendo um histórico de utilização.

---

## 📝 Resumo do Sistema
O sistema permite:
- Cadastro de medicamentos, incluindo nome, dosagem, frequência e horários de uso.  
- Persistência dos dados em banco de dados local SQLite, com possibilidade de sincronização.  
- Listagem de medicamentos cadastrados.  
- Notificações para lembrar o usuário do horário de uso.  
- Interface intuitiva, focada na usabilidade e acessibilidade.
